## 2. 公式ドキュメントでの確認が必要な事項(記憶に基づく記述)

- Lambdaで使えるPythonランタイムの識別子(テンプレート既定は `python3.13`、コードは3.11以上が必要)。
- EventBridge Schedulerの `at()` 式、`EndDate`、`RetryPolicy` の受理形式と下限値。
- `AWS::Lambda::EventInvokeConfig` の下限値(再試行0、イベント寿命60秒)。
- 予約同時実行数の確保に必要なアカウントのクォータ。
- SNSトピックを暗号化した場合のCloudWatch Alarmからの発行可否(現状は非暗号化)。
- S3の条件付き書込みとチェックサム属性の取得API、バケットポリシーでの強制方法。
- KMS非対称鍵の料金、削除待機期間、`Sign`/`Verify` の引数。
- Fargate/Lambdaでのブラウザsandboxの制約(EC2を選んだ理由の前提)。
- CloudWatch Syntheticsの料金(代替案の比較に使用)。
- すべての料金(`COST_ESTIMATE.md` は推定)。
