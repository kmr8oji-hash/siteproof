# SiteProof 実演動画（2〜3分）操作手順と台本

## 準備（録画の前に）

1. 録画用の空のデータフォルダでSiteProofを起動します（AWS・外部通信なし）。
   ```powershell
   py -3.15 -B -m src.noxiworks.app --data demo-video-data --no-browser
   ```
2. ブラウザ（Firefoxなど）で `http://127.0.0.1:8765/` を開きます。ウィンドウ幅は1440px程度にします。
3. 履歴を見せるため、録画の前に「変更なし」と「撮影が不安定」を1回ずつ検査しておきます（HOMEの「オフライン検査」から）。
4. 録画中は、AWSコンソール、認証情報、`.local/` のファイル、メールの受信箱を画面に出さないでください。ターミナルとHOMEパネルの下に表示されるデータフォルダのパスにはユーザー名が含まれるため、映る場合は短いパス（例：`C:\sp-demo`）で起動してください。
5. 画面はすべて合成fixtureです。冒頭で「サンプルデータ（デモ）」の表示を見せます。

## 撮影のコツ

- 各画面で2〜3秒止めてから操作します。マウスの動きはゆっくりにします。
- 検査の待ち時間（約15秒）は、そのまま見せるか、字幕「検査中（約15秒）」を入れて短く編集します。
- 差分レビューのスライダーは、左右にゆっくり1往復だけ動かします。
- 実測の結果（2026-11-19の実サイト比較：Desktop・Mobileとも変更なし、差分0ピクセル）を紹介する場合は、READMEの検証記録の表を映し、実測と合成fixtureを区別して説明します。実サイトの撮影画像は動画に入れません。

## 動画で言わないこと

- 「品質を保証する」「完全に自動で止まる」「画像も定期的に監視している」「実サイトをアプリから撮影できる」とは言いません（いずれも未実装・未実証です）。
- AWSのアカウントID、メールアドレス、リソース名の全体は映しません。
